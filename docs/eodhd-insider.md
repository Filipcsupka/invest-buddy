# EODHD Form 4 fallback

SEC EDGAR remains the primary insider source. The daily collector already requests submissions and Form 4 XML for US issuers at no EODHD call cost. A Form 4 backfill also exists. EODHD's `/sec-filings/{SYM}/form4` costs 10 calls per page, so one page for U active US universe names costs `10 × U` calls; 36 names would cost 360 calls. More than 100 filings in the 90-day window require additional pages, each costing another 10 calls. The exact active US count comes from the database, not the static universe file.

`npm run insider:eodhd -- --dry-run` reports due names and the one-page estimate without an API key or EODHD requests. Each successful SEC ticker check records its own date, including checks with no Form 4 filing. A check in the last two days suppresses the fallback. Missing or stale SEC coverage permits a paid refresh, at most once every two days per ticker. The default cap is 10 symbols per run (`--max-symbols` changes it). Live collection needs `DATABASE_URL` and `EODHD_API_KEY`; schedule the job separately. `npm run insider:eodhd -- --dry-run --fixture src/data-providers/eodhd/fixtures/form4.json --as-of 2026-05-16` checks parsing without a database, key, network call or write.

Only non-derivative P/S lines with valid dates and positive shares enter `insider_transactions`. Each line carries `source_id=eodhd`, `first_observed_at` and `display_allowed=false`. SEC rows take precedence by accession: the fallback skips an accession that has SEC rows, and a later SEC ingestion removes EODHD rows for that accession. This prevents double counting when both sources hold a filing. New vendor and SEC rows observed after a historical score date cannot enter its net-buy calculation. Existing SEC rows lack a reliable first-observed date and retain their earlier replay behavior. A collected net-buy fact is tagged `eodhd` when any vendor line contributes. Public insider events and the display-oriented insider read exclude EODHD while display rights are unverified.

The fixture proves the parser and job flow. **UNVERIFIED:** live EODHD payload shape, coverage, pagination completeness, exact billed calls on retries, ALL-IN-ONE access and display rights. A page limit of five fails that symbol rather than treating an incomplete 90-day history as complete. The job records each symbol failure and continues, except account authentication or allowance errors stop the run.
