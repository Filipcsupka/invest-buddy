# Flex Trades for the private owner ledger

The owner must edit the existing IBKR Activity Flex Query used by `FLEX_QUERY_ID`. In Client Portal, open **Performance & Reports > Flex Queries**, select that Activity Flex Query, and add the **Trades** section with **Executions** as its level of detail. Select these fields: Asset Class, Currency, FX Rate to Base, Symbol, Trade ID, Trade Date, Quantity, Proceeds, IB Commission, and IB Commission Currency. Keep XML output and the existing Last 365 Calendar Days period, Change in NAV, Cash Report, Open Positions, and Conversion Rates sections. Save the query and check one downloaded XML response for `<Trades><Trade ... /></Trades>` before the next portfolio job. IBKR documents the [query editor](https://www.ibkrguides.com/orgportal/performanceandstatements/activityflex.htm) and [Trades fields and levels](https://www.ibkrguides.com/reportingreference/reportguide/tradesfq.htm). This repository does not change the IBKR query.

Migration 088 adds private `portfolio_baseline.trades` and `trade_from_date` storage. The Flex import keeps stock executions with a valid date, symbol, quantity, proceeds, fee, and EUR conversion rate. It skips other asset classes and rows that cannot be converted. A repeated Trade ID is counted once. The latest baseline keeps the available trade window; older manual baselines may have no trades. An add can use its date history only when the Flex period covers the start of the current month.

The owner page marks net sale proceeds as recycled cash. Later purchases consume the oldest sale balance, and the current broker cash caps the total. The allocation gives sustained signals first use of that balance. It applies draft event-driven limits of 20% of total portfolio value for the sleeve and half the usual `sizingCap()` for each name, under `ALLOCATION_CONFIG.version` `2026-10-18.1`. The owner must confirm both thresholds. Dates held are shown only when the imported purchases cover the current quantity. Gain since cost uses the position's reported cost basis. These are facts and review inputs; the page has no exit instruction.
